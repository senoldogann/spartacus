# User Personas

## Primary: AI Platform Engineer

**Role**: Evaluates, selects, and operates AI developer tools for engineering teams.

**Goals**:
- Objectively compare coding agents on company codebase
- Produce evidence for procurement decisions
- Detect model regressions before they impact developers

**Pain points**:
- Public benchmarks don't reflect internal tech stack
- Vendor demos are cherry-picked
- No standardized evaluation framework

**How RepoBench helps**: Automated, reproducible benchmarks on actual repository history with deterministic metrics.

---

## Secondary: Engineering Manager

**Role**: Makes tool adoption decisions for their team.

**Goals**:
- Justify AI tool spending with data
- Ensure code quality standards are maintained
- Minimize adoption risk

**Pain points**:
- "It feels faster" is not a valid procurement argument
- No way to compare before/after or between options
- Risk of committing to the wrong agent

**How RepoBench helps**: Concrete comparison reports showing task pass rate, cost, and speed across agents.

---

## Tertiary: Staff/Principal Engineer

**Role**: Sets technical standards and evaluates tooling impact.

**Goals**:
- Understand agent strengths and weaknesses on specific task types
- Identify where agents add value vs. create risk
- Define guardrails for AI-assisted development

**Pain points**:
- Agent output quality varies by problem type
- Hard to systematically test across diverse codebases

**How RepoBench helps**: Task-level granularity reveals which types of bugs each agent handles well.
