# Success Metrics

## North Star

> A team can run a reproducible benchmark on their own repo, compare 2+ agents, and make a data-backed adoption decision — in under one day.

## v1 Release Criteria

| Metric                                               | Target       |
| ---------------------------------------------------- | ------------ |
| Public repo benchmarks completed                     | >= 3 repos   |
| Benchmark tasks per repo                             | >= 10        |
| Agents compared per benchmark                        | >= 2         |
| Reproducibility (same task, same agent, same result) | >= 95%       |
| Setup time (clone to first benchmark)                | < 30 minutes |
| Patch apply metric accuracy (vs human review)        | >= 98%       |
| Test pass metric accuracy                            | >= 99%       |

## Operational Metrics

| Metric                                | Target    |
| ------------------------------------- | --------- |
| Sandbox escape incidents              | 0         |
| Secret leakage incidents              | 0         |
| Average benchmark run time (20 tasks) | < 2 hours |
| Worker crash rate                     | < 1%      |

## Growth Metrics (post-launch)

| Metric                               | Target |
| ------------------------------------ | ------ |
| GitHub stars (3 months)              | >= 500 |
| Monthly active installations         | >= 50  |
| Community-contributed agent adapters | >= 2   |
